# Hotstar-Ad--muter
A Chrome extension that automatically mutes the audio of advertisements when watching content on Hotstar.

## Installation

1.  Download the latest version of the extension from
2. ```bash
   git clone https://github.com/Akki113131/Hotstar-Ad--muter
   ```
2.  Open your Google Chrome browser and navigate to `chrome://extensions/`.
3.  Enable "Developer mode" in the top right corner.
4.  Click on "Load unpacked" in the top left corner.
5.  Select the directory where you extracted the downloaded extension files.

## Usage

Once installed, the extension works automatically in the background whenever you browse the Hotstar website. You don't need to do anything!
